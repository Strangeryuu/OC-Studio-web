# OC Studio Web：高级功能验收及部署前核查

> 适用分支：`web-dev`。此文档区分**已由 GitHub Actions 验证**的功能和**仍需真实浏览器 / VPS 手工复核**的功能。请先使用测试账号与空白资料库执行恢复测试。

## 自动化验收

原版回收站、模板/分类、全局搜索以及 `.ocbak` 备份与迁移已纳入 `scripts/cloud-http-smoke.cjs`，在 `.github/workflows/web-cloud-check.yml` 的独立 PostgreSQL 16 作业里，执行实际登录、HTTP 请求、迁移和数据检查。

| 业务 | 实际自动验收场景 |
| --- | --- |
| 回收站 | 小说及章节整树软删除、同批恢复、原数字父级保持；PGlite 覆盖永久清理及成员权限 |
| 模板与分类 | 保存资料库配置、并发版本冲突、隔离及分类重命名 |
| 全局搜索 | 角色、词条、小说等跨类型检索；不同资料库结果隔离 |
| 云端 `.ocbak` | 私有媒体、角色国籍、章节树、标签、分类、回收站条目及当前内容导出/空库导入；重新生成 UUID 和原数字 ID；已有数据禁止覆盖 |
| 桌面 v1 `.ocbak` | 数字国籍关系、数字标签、内嵌 PNG 图片转私有媒体；年代、世界信息、灵感和创作日志经扩展配置保留并能再次导出 |
| 备份防护 | 校验当前实体与图片归属、格式版本和时间戳；外站 Origin 与匿名导入拒绝；无效备份不会写入部分资料 |

验证流水线：<https://github.com/Strangeryuu/OC-Studio-web/actions/workflows/web-cloud-check.yml>。只有 **Web、PostgreSQL 两项成功** 后才发布 Docker 镜像。可通过每次提交关联的具体 Run 核对结论，不复用旧版测试结果。

## 真人浏览器操作验收（待在部署环境执行）

1. **回收站**：分别用 owner、admin、editor、viewer 登录；创建两层子章节后删除小说，在回收站恢复；打开章节查看正文及父子关系。检查 editor、viewer 的恢复和永久删除权限，以及弹窗取消和版本冲突提示。
2. **模板和分类**：创建自定义分类并修改模板组件排序、启用状态；在此分类创建词条；改名后检查所有子词条仍可见、搜索可命中、并发修改会得到版本冲突提示。两个浏览器同时修改配置时，后提交者应收到版本冲突提示。
3. **全局搜索**：分别输入标题、别名、正文词与两个关键词；从结果跳到角色、国家、词条和小说章节；检查搜索结果不会跨资料库泄露，移动端导航正常。
4. **云端备份恢复**：在有测试图片、章节、标签、回收站内容的源资料库下载 `.ocbak`；在同 VPS 新建完全空白资料库导入；逐一打开图片与小说，检查回收站条目、图片及模板。再次导入同目标应被拒绝；异常备份应留下空白目标。
5. **桌面原版归档**：使用从桌面版真实导出的 `.ocbak` 重复上述测试。检查图片、文档、年代和日志；包含 SVG、视频、超大图片、旧版历史附件或自定义插件数据的备份应另设专用样例。云端暂未渲染的桌面附加信息会随备份保存以便再次导出。
6. **多成员与多设备**：至少两名真实账号、不同浏览器同时编辑同一词条，验证 409 冲突和草稿保护；切换资料库后再次检查私有媒体的 403/404 保护。
7. **VPS 备份演练**：先分别备份 PostgreSQL 与 `MEDIA_ROOT`，在独立测试实例执行恢复，并核对私有图片；升级到 GHCR SHA 镜像后再验证登录/地图/小说。数据库迁移涉及状态变更，升级失败应按备份计划恢复，避免仅回滚容器镜像。

## 上线提醒与兼容范围

- `.ocbak` 是便携内容归档：单次上传限制约 60 MB，导出也受媒体数量和体积限制。**生产级灾备仍需 PostgreSQL 数据库 + 私有媒体目录的成对快照**。
- 原版桌面备份里额外的 `periods`、`meta`、`config`（包括灵感）与 `journal` 会保存在云端 `desktop-extras` 设置中，并参与再次导出。相关数据的**完整云端可视化编辑器**仍需后续移植。
- 目前自动化验证主要覆盖 PNG/JPEG/GIF/WebP 私有图片；原版 SVG、视频、旧版历史附件和较大数据集的真实迁移尚需专题验收。
- 可在测试 VPS 使用 `docs/web-docker-deployment.md` 的 Compose、迁移和健康检查步骤；正式迁移前先验证备份恢复。**GitHub Actions 通过仅代表 CI 环境通过，不能代替公网 HTTPS、移动浏览器与生产数据恢复验收。**

> 2026-11-20 更新：当前 Web 分支已停用修改历史界面与逐版本接口，`.ocbak` 按当前快照导出；管理员的定时世界观归档在 `/admin/backups` 配置，整站数据库及媒体灾备仍由 `deploy/backup.sh` 单独执行。最新自动化执行记录见 GitHub Actions，真实 Android/iOS 浏览器及生产 VPS 恢复仍需现场验收。
