# OC Studio Web · OC-editor 地图高级视图移植（2026-11-20）

本阶段参考 [OC-editor 地图模块](https://github.com/nekibud/OC-editor/tree/main/src/features/map)，在 `web-dev` 上复用原有地图实体、私有图片权限和世界生成器 Worker。改动集中在地图查看与生成界面，保持原有 API 和 PostgreSQL 地图记录兼容。

## 1. 3D 地球

- 打开世界观 → **地图** → 选择比例约为 **2:1** 的世界底图 → 点击 **3D 地球**。
- 使用 OC-editor 的 WebGL2 cube-sphere 六面球体渲染器，顶点颜色采样当前地图的私有底图。
- 鼠标拖动旋转、滚轮缩放；移动端单指旋转、双指缩放；右上角可复位视角。
- 有世界地图的生成快照（`mapSeed` 和 `mapParams`）时，按种子在 Worker 中重新生成高程层，恢复实际地形起伏。生成期间保持贴图球体可用。
- 手动上传的 2:1 底图也能使用球体贴图预览。缺少生成快照时，只显示球面贴图，页面明确标识。
- WebGL2 不可用时显示友好提示，用户可切换回现有平面地图。地图锚点、国界及道路保留在原 2D 编辑器，切换显示模式不写入数据库。

## 2. 地形剖面

- 打开有生成参数快照的地图 → **平面** → **地形剖面**。
- 在底图上**依次点击两个点**（桌面鼠标或手机触屏），系统调用原有 `renderMapProfile()` 和地图生成器 Worker，依照归一化坐标采样高度、水体、生物群系、温度与湿度。
- 剖面抽屉显示高程变化曲线、地形与生物群系色带、总距离；采样期间显示进度，失败时保留错误信息。
- 剖面线只用于阅读，不会写入地图政治标注、锚点或世界观实体。关闭剖面与切换地图将清理当前采样状态。

## 3. 地图生成器

- 现有生成器继续支持世界/区域、地形预设、种子、陆地/山脉/气候/湖泊参数、多视图与 PNG 导出。
- **新增 3D 预览**：生成世界地图后在视图栏切换 **3D 预览**，直接使用生成器当前 Worker 回传的高程层，无须二次完整生成；3D 预览完成后仍可将底图及其他视图写回地图。
- 云端保存沿用 `OriginalNotesCloudAdapter` 及经过权限控制的私有媒体上传接口；生成视图不改变地图记录格式。

## 已保留的原有能力

世界观隔离、地图重命名/删除、国家/事件/词条锚点、国界/道路标注、地图生成结果与多档视图、`.ocmap` 导入导出、包含锚点的 PNG 导出、阅读权限与桌面模式。
